MyStock: Clothing Inventory Management Software
Overview
MyStock is a comprehensive software solution designed to manage and streamline the inventory processes for clothing stores. The application includes features for managing products, suppliers, clients, sales, and purchases, providing an all-in-one tool for inventory management.

Features
Login Screen
![Login](https://github.com/user-attachments/assets/627f0f12-d848-4d9d-ac97-bc198a7b53dc)

Purpose: Provides secure access to the software.
Details: Users must enter their username and password to log in. The option to change login information is also available.
Security: Ensures that only authorized personnel can access the system.
Home Screen 
![home](https://github.com/user-attachments/assets/bffa3f66-f935-4bb8-b32d-5cdb4d40a308)

Purpose: Serves as the main navigation hub of MyStock.
Details:
Vendeurs: Manage sellers.
Produits: Handle product information.
Ventes: Monitor sales transactions.
Achats: Manage purchase orders.
Fournisseur & Clients: Handle supplier and client details.
Statistique: Access various statistics and reports.
Sortir: Exit the application.
Supplier and Client Management 
![cients   Fourni](https://github.com/user-attachments/assets/9534c28d-d57d-4506-b5b8-21bedf3087d1)

Purpose: Allows users to manage both suppliers and clients within the system.
Details:
The user can add, modify, delete, and search for suppliers and clients.
Fields include ID, name, phone number, address, and city.
Separate sections for suppliers and clients for clear categorization.
Purchasing Management 
![achats](https://github.com/user-attachments/assets/504cfe4a-aa5d-487d-a4cc-7ee2c8013c6d)

Purpose: Facilitates the management of purchase orders.
Details:
Users can input product barcodes, names, prices, quantities, and select suppliers.
The system calculates the total price, and users can validate the purchase order.
The list of purchases is displayed, showing all necessary details like supplier, product name, quantity, and total price.
It also includes fields for total price, payment made, and remaining balance (solde).
How to Use
Log in to the System: Enter your credentials on the login screen to access MyStock.
Navigate through the Home Screen: Use the main screen to access various modules:
Manage sellers, products, sales, purchases, suppliers, and clients.
Generate statistics and reports as needed.
Manage Suppliers and Clients: Use the Fournisseur & Clients module to keep track of your business partners and customers.
Add or update details as needed.
Handle Purchases: Navigate to Achats to create and manage purchase orders.
Input all necessary details like product information and supplier.
Validate and record the purchase order in the system.
